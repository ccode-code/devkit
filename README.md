# DevKit

桌面开发者工具箱。打开软件后，通过一个开关即可监听本机与手机发出的 HTTP/HTTPS 请求；后续会持续集成日常开发、网络调试类小工具。

## 当前状态

规划阶段。完整方案见 [docs/PLAN.md](docs/PLAN.md)。

## 规划中的第一个工具：HTTPS 抓包

- 抓取并展示请求/响应（方法、URL、状态码、头、Body、耗时、大小）
- 一键生成根证书并提供手机安装引导（含二维码）
- 断点修改请求/响应、请求重放
- 导出 HAR
- 一键开关系统代理，退出时还原

## 架构

- **桌面壳**：Tauri 2（跨平台）
- **后端**：Go 独立进程（`devkit-core`），承载全部业务能力
- **前端**：React + TypeScript + Vite
- **通信**：本地 HTTP + WebSocket，绑定 127.0.0.1 随机端口，Bearer token 鉴权

```text
apps/desktop/     Tauri 壳与 React 前端
core/             Go 后端
scripts/          Go 二进制构建脚本（按 target triple 命名）
docs/             设计与规划文档
```

**Rust 的边界**：Tauri 的壳由 Rust 编写，无法完全避免。但 Rust 只负责拉起/回收 Go 进程、读取握手信息、把端口和 token 交给前端、注册单实例插件，约 50–80 行，不承载任何抓包、代理、证书或系统配置逻辑。取舍是换来成熟的跨平台打包、签名、公证和托盘体系。

## 使用边界

本工具仅用于监听**本人设备**与**已获得明确授权**的流量。根证书私钥只保存在本机，不随应用分发。请勿用于任何未经授权的抓包或监听。
